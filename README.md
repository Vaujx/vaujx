## Things I've built

**[GIF Forge](https://github.com/Vaujx/gif-forge)** · Python, pywebview, ffmpeg, anime.js
Online GIF converters make you upload your videos to someone else's server. GIF Forge does it locally: pick an MP4, trim it, choose a size and frame rate, and get a clean GIF. It uses ffmpeg's two-pass palette method for much better colors than the usual one-pass output, and ships as a single Windows `.exe` with nothing to install.

**[DESKMAN](https://github.com/Vaujx/DESKMAN)** · HTML, CSS, JavaScript
Messy Downloads and Desktop folders. DESKMAN scans a folder in the browser and sorts files into categories (Pictures, Videos, Documents, Archives and so on), with batch rename. It shows a preview of every change first, so nothing touches your disk until you've approved it.

**[ForeignLanguage](https://github.com/Vaujx/ForeignLanguage)** · Python, Selenium
A folder full of videos with titles in a language you can't read. This tool scans the folder, spots the non-English filenames, translates them through Google Translate, and renames the files. A simple `.bat` launcher handles setup, so there's no command-line fuss.

**[BAAC](https://github.com/Vaujx/BAAC)** · Python (Flask)
A community web app for a barangay, with local data, history, and notable places, plus user authentication. Deployed with a Procfile.
